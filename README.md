# Asia Cup Power BI Analysis
End-to-end Power BI project using Asia Cup match data to deliver interactive dashboards, KPIs, and data-driven cricket insights.
## Project Overview
This project focuses on creating a comprehensive Power BI dashboard using historical Asia Cup cricket data.
The dashboard is designed to serve both casual cricket fans and advanced analysts by combining high-level
summaries with deeper analytical insights.

## Objectives
- Present historical Asia Cup data in a clean and interactive Power BI dashboard
- Identify key KPIs such as total matches, wins, and win percentages
- Analyze correlations between toss decisions, batting order, and match outcomes
- Provide a dedicated analytical section for the India vs Pakistan rivalry
- Follow professional project and documentation standards suitable for GitHub

## Dashboard Pages
1. Tournament Overview
2. India vs Pakistan Rivalry
3. Performance trend
4. Tournament trend

## Tools Used
- Power BI
- Microsoft Excel
- DAX (Data Analysis Expressions)

## Notes
- The analysis is based on team-level match data
- Ranking logic is used to avoid aggregation bias
- The project emphasizes clarity, accuracy, and storytelling
